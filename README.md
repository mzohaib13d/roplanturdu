# 🌊 RO Plant Urdu — Complete Technical Guide

**RO Plant Urdu** is a modern, responsive web application designed to educate operators and engineers about industrial and commercial Reverse Osmosis (RO) water purification systems using clear Urdu explanations.

### ✨ Features
* **Interactive Water Flow Diagram:** Visual step-by-step navigation of the entire filtration process—from Raw Water Tank to Permeate Output.
* **Component-by-Component Breakdown:** Detailed explanations of Sand Filters, Carbon Filters, Softeners, Cartridge Filters, High-Pressure Pumps, and RO Membranes.
* **Troubleshooting & Failure Analysis:** Comprehensive tables highlighting potential component failures and their operational impacts.
* **Terminology & Calculations:** Quick-reference glossary for key terms (TDS, Recovery Rate, Feed Water, Permeate, Reject).
* **RTL & Mobile First Design:** Native Right-to-Left (RTL) layout optimized for mobile, tablet, and desktop viewing.

### 🛠️ Tech Stack
* **Framework:** Next.js 16 (App Router)
* **Styling:** Tailwind CSS 4.1
* **Animations:** Framer Motion
* **Icons:** Lucide React
